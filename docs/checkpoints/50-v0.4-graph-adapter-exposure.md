# v0.4 Phase 14: Graph Adapter Exposure

Phase 14 exposes the already-accepted structural service without moving graph
policy into adapters.

## Implemented

- `CortexWeaveService` now exposes transport-neutral find, relation, and impact
  calls for graph adapters.
- `cortexweave graph` provides `find`, `neighbors`, `callers`, `callees`,
  `references`, `implementations`, `tests`, `dependencies`, `dependents`,
  `impact-symbol`, and `impact-path` commands.
- MCP exposes the equivalent `graph_*` tools. `graph_find` returns exact node
  IDs to use with relation tools; every response preserves graph snapshot,
  limits, typed paths, confidence, and truncation.
- CLI permits the structural service's validated hard bounds. MCP caps requests
  at 100 nodes, 500 edges, and depth 4, validates them before service calls,
  and defaults to the core's current-only graph state.

## Verification

- MCP contract coverage indexes an interface, implementations, caller, and test
  fixture; it proves find, bounded implementation lookup, impact reachability,
  provenance, and oversized-bound rejection.
- CLI coverage verifies graph subcommands and explicit stale/bound options are
  present in the public parser help.

## Boundary

Phase 14 adapter exposure is complete. Phase 15 graph metrics and doctor,
performance baseline capture, and Phase 16 documentation expansion remain in
the next planned work. Phase 13 observation mapping remains deferred stretch
scope.
