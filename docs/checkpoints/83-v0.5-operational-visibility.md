**Status:** Complete

Phase 11 adds bounded, observational visibility for the verified Experience
and memory-consolidation substrate.

- `doctor` verifies all episode and Experience persistence tables, assessment
  tables, FTS projection availability, missing Experience FTS rows, and SQLite
  foreign-key integrity.
- Metrics expose persisted episode/Experience/assessment counts, deterministic

  requested Experience search components, context source-category utilization,
  and bounded operation latency.
- Evaluation metrics have a timestamp-free, versioned JSON report serializer;
  duration is represented as integer microseconds for repeatable artifacts.
- Focused fixtures cover persistence health after migration and metric counters;
  the full suite remains green.

All metrics are process-local or derived from durable counts and are strictly
observational. They do not modify ranking, budgets, eligibility, consolidation,
or any automatic action. Historical-staleness guidance explicitly keeps prior
source/graph snapshots subordinate to current code and task evidence.
