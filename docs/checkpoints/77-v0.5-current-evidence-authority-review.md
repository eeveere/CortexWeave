# v0.5 Checkpoint 77: Current-Evidence Authority and Displacement Review

**Date:** 2026-08-31

**Scope:** Breakpoint 8 adversarial review on GPT-5.6 Sol/xhigh

## Result

The authority gate passes after three corrections. First, Experience selection
now exposes its deterministic search, lifecycle, verification, strength,
outcome, and `historical_supplemental` authority facts in the packet
explanation. Second, Experience is no longer eligible for generic source
lookup, working-set activation, pins, or temporal admission. Its sole path into
a packet is the bounded active-failure search added in Phase 7. Third,
member-event deduplication spans the complete selected historical set.

Experience member event IDs are now accumulated across the complete selected
historical set. This prevents the same immutable event from consuming ordinary
Event context and Experience context, or from being counted through two
selected Experiences.

| current code vs matching historical path/snapshot | current code remains `current`, is selected first, and is never replaced by the historical item; immutable snapshot resolution continues to report its own revision and hash |

| exact member-event duplicate | a selected Event blocks the Experience containing that exact event; selected Experience members are also tracked against later Experience candidates |
| Experience search unavailable | ordinary context succeeds, no Experience item is emitted, and the explanation reports `search_unavailable` |

Focused tests cover current-code ordering, active failure ordering, lifecycle
dominance, member-event deduplication, stale graph behavior, generic admission
rejection, and unavailable-search degradation. The persistent Experience
repository proof continues to cover current, changed, missing, deleted, and
stale/unavailable historical references.
