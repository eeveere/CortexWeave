# Checkpoint 38: v0.3 Harness-Controlled Context Plan

## Decision

The v0.3 plan now begins with analyzer readiness, implementation-coverage
evaluation, and a native-harness control contract. The existing memory trust,
duplicate detection, and consolidation work remains in scope after those
foundations.

## Evidence

Real OPiHype MCP trials showed that a generic client can choose an unintended
tool or bypass a returned context packet. Enabling the Python analyzer and
rebuilding the workspace converted generic text fragments into named Python
symbols, producing materially better implementation context.

## Boundary

The native harness enforces workflow and evidence policy. CortexWeave remains
the transport-neutral cognitive substrate and does not become an agent runner.
