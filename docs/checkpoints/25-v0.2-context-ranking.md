# Checkpoint 25: v0.2 Context Ranking

## Result

PASS. Phase 7 ranks the bounded candidate pool with a configurable,
deterministic, source-aware formula and records every score component.

## Verified Behavior

- Semantic, lexical, task, working-set, recency, provenance, freshness, and
  structural relationship weights are independently configurable and validated.
- Working-set and retrieval inputs are normalized to `[0, 1]`; invalid numeric
  inputs cannot produce a non-finite final score.
- Direct memory full-text matches merge with temporal and working-set forms by
  stable source identity and retain decision or failure reasons.
- A fixed evaluation covers current implementation, historical decision,
  recent-change, exact-symbol, resume-session, and cross-language questions.
- An older lexically relevant decision outranks unrelated current code without
  allowing recency to override source truth by itself.
- Exact ties remain deterministic through source type and stable source ID.

## Boundary

Ranking is deterministic application logic. It consumes normalized retrieval,
state, temporal, and structural signals; it performs no model inference and
contains no adapter-specific behavior.
