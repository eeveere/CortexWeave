## Completed Integration

- Workspace reindex and watcher batches now reconcile source state first and
  finish with one fenced `IfNeeded` graph repair generation. Their outcomes
  distinguish source updates from graph-only analysis, projection, and final
  repair state.
- A no-op reindex reports an explicit current graph-repair outcome without
  creating a generation or recomputing embeddings.
- All CLI commands that accept a workspace value now resolve IDs, registered
  names, absolute roots, and file URIs through the same selector policy as MCP.
- `graph rebuild <workspace> [--force]` is available in both CLI and MCP. It
  invokes the application service repair path rather than a separate adapter
  implementation.
- Graph status includes the latest repair generation. Doctor output includes
  that status, so an active, failed, or interrupted repair is diagnosable even
  while structural reads remain protected.
