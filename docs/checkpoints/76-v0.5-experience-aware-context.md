# v0.5 Checkpoint 76: Experience-Aware Context

**Date:** 2026-08-31

**Scope:** Phase 7 on GPT-5.6 Terra/high

## Result

`ContextSourceType::Experience` is now a distinct historical source. A
`ContextRequest` can carry an `active_failure_signature`; when supplied, the
context service searches a bounded, separate Experience pool. It accepts only
active Experiences with strong or moderate evidence, a deterministic terminal
verification (`verified_passed` or `verified_failed`), and a terminal outcome
that is not inconclusive or abandoned. Exact signature matches receive the
explicit exact-signature reason; compatible matches and verified outcomes have
their own reasons.

Historical rendering is compact, whitespace-normalized, byte-capped, and
prefixed `Historical experience (not current evidence)`. It does not claim
that the historical result describes the present workspace.

## Authority and Budget Boundary

Ordinary context is selected unchanged before the Experience pool is examined.
Experiences receive only unused packet capacity and additionally obey
`context.experience.token_budget`; they cannot evict code, tasks, documents,
memories, or events. Configuration caps candidate count at 50 and historical
token budget at 2048.

The packet explanation now records the candidate count, selected Experience
IDs, and a precise degradation reason: not requested, disabled, search
unavailable, no eligible result, budget exhausted, or deduplicated. Search
failure therefore preserves ordinary context rather than failing the packet or
inventing history.

## Proofs

- An accepted immutable Experience with an exact active compiler signature is
  added after the current task state, retains historical freshness, and stays
  within both packet and Experience budgets.
- A selected current Event that is a member of the matching Experience blocks
  that Experience from consuming both context categories.
- A malformed active signature makes Experience search unavailable while the
  ordinary current task context remains available.
- A zero packet budget reports historical budget exhaustion without emitting
  an Experience.
- Configuration tests cover default values and invalid historical candidate and
  token ceilings.

Phase 7 is complete. Breakpoint 8 remains unstarted.
