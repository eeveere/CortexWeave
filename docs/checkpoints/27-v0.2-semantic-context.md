# Checkpoint 27: v0.2 Semantic Context

## Result

PASS. Phase 9 exposes the completed context assembler as a transport-neutral
service operation and through the CLI and MCP adapters.

## Verified Behavior

- `CortexWeaveService::semantic_context` accepts `ContextRequest` and returns a
  bounded `ContextPacket` without adapter-specific types.
- The CLI `context` command supports query, workspace, task/session, budget,
  source filters, path scopes, and language scopes.
- MCP `semantic_context` uses the same request fields after deterministic
  workspace resolution and rejects budgets above 65,536 tokens.
- Facade, CLI, and MCP tests confirm task-aware and memory-only packets through
  their real service paths.

## Boundary

Assembly, ranking, and budget enforcement remain inside `ContextService`.
Adapters only translate their inputs and serialize the domain packet.
