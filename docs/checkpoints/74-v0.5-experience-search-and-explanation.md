# v0.5 Checkpoint 74: Experience Search and Explanation

**Date:** 2026-08-30

**Scope:** Phase 6 on GPT-5.6 Terra/high

## Result

Experience retrieval is now a bounded, workspace-scoped deterministic service.
It merges independent exact-signature, compatible-component, FTS, exact-path,
exact graph-stable-key, and recent candidates; it then loads immutable records,
applies outcome, evidence-strength, lifecycle, and time filters, and gives each
result an inspectable score breakdown.

Exact signature receives 1000 points, more than the combined maximum of every
weaker candidate signal. Compatible components, lexical FTS, exact path, and
exact graph key contribute smaller bounded values. Results then tie-break by
newest immutable record and ID. Empty lifecycle filters include active records
only; disputed, refuted, and superseded experiences require an explicit filter.

`CortexWeaveService::search_experiences` exposes search, and
`CortexWeaveService::experience_get` returns the immutable record, append-only
assessments, derived lifecycle, and historical-reference resolution. Resolution
reports separate document and graph resolution status while retaining the
original historical path, revisions, hashes, and stable key. It never rewrites
historical references to current code. Checkpoint 75 refines this contract.

## Storage

Migration `0009` adds workspace-local indexes for exact failure keys, common
filters, snapshot paths, and historical graph stable keys. The existing FTS5
projection remains the lexical source. Each primitive candidate query is
capped at 200 and output at 50 results; the bounded merged union is scored in
full as refined by Checkpoint 75. No embedding inference, cross-workspace
search, popularity/reuse score, or graph-neighbor expansion was added.

## Proofs

Focused tests prove exact-signature dominance and safe bounded FTS query
construction. The immutable aggregate persistence proof now validates all five
candidate sources against a real Experience and its FTS, path, and graph
snapshot projections.

Breakpoint 7 remains the planned Sol/high retrieval-correctness review.
