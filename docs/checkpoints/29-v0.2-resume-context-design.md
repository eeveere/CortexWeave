# Checkpoint 29: v0.2 Resume Context Design

## Result

PASS. Phase 10 design defines deterministic session/task selection, separates
the active session from historical evidence scope, and specifies a bounded
resume packet without model-generated synthesis.

## Decisions

- Explicit scope wins; inferred sessions and tasks use stable timestamp and ID
  ordering and report the selected rule.
- A fresh current session may consume checkpoint, memory, change, and working-set
  evidence from the prior task's evidence session.
- Checkpoints are deterministically rendered as required context after task
  state; raw event streams are aggregated by path.
- Open failure claims require unsuperseded failure memory or explicit checkpoint
  state. Compiler and test events remain evidence only.
- Current source is hydrated from explicit persisted paths and normalized
  symbols before any optional semantic mechanism.
