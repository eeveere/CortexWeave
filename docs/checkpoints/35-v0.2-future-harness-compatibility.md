# Checkpoint 35: Future Harness Compatibility

## Result

PASS. A dedicated harness can request and update context every reasoning cycle
without depending on MCP-specific semantics.

## Reviewed

| Surface | Direct application contract |
| --- | --- |
| Context request/packet | Domain structs accepted and returned by `CortexWeaveService` |
| Event flow | `record_event` accepts typed events with explicit provenance |
| Session/task state | Lifecycle methods operate directly on domain state |
| Working set | Activate and inspect methods are facade operations |
| Pins | Pin and unpin methods require only source identity and scope |
| Checkpoints | Create/latest methods use structured domain checkpoints |
| Resume | `resume_context` returns selection diagnostics and a bounded packet |

No core, domain, storage, retrieval, or indexing module imports MCP types. The
native-harness regression now exercises indexing, retrieval, memory, event flow,
semantic context, working-set activation, pinning, checkpointing, lifecycle
completion, and resume through the facade alone.
