# v0.4.1 Final Hardening

**Date:** 2026-08-29  
**Scope:** Terra/high remediation of the four Breakpoint-2 blockers from
checkpoint 59. Local, copied-repository, and fresh Crush client gates passed;
v0.4.1 Definition of Done is complete.

## Completed Remediation

1. A durable active, failed, or interrupted graph-repair generation now takes
   precedence over an otherwise-current revision watermark. A restored source
   produces a replacement `if_needed` generation and converges without graph
   analysis or embeddings. Graph status also reports `is_current: false` while
   such a generation blocks structural reads.
2. Workspace discovery prunes `.git` directories before descent while retaining
   deliberate hidden project files. A scanner regression verifies that
   `.git/config` is never indexed.
3. The package, lockfile, CLI `--version`, and MCP initialize response now all
   identify this release as `0.4.1`.
4. Exact symbol/path terms in graph-aware retrieval create a zero-distance seed
   evidence path only when the graph identifies that declaration. The evidence
   retains node identity, revision, and read limits without inventing a graph
   relationship. Context reserves one bounded evidence-bearing item and may
   truncate its code body to its structural budget.
