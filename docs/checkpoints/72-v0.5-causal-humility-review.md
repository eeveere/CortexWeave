# v0.5 Checkpoint 72: Causal Humility Review

**Date:** 2026-08-30

**Scope:** Breakpoint 5 adversarial review on GPT-5.6 Sol/xhigh

## Result

The original Phase 5 implementation did not pass review.  The review found and
corrected material truth-boundary defects before any acceptance proof was
attempted:

- the final attempt's first result had been mislabeled as
  `terminal_verification` instead of its owned `attempt_verification`;
- persistence incorrectly required every earlier conclusive attempt to appear
  in the terminal observations;
- scope comparison omitted subject kind and registered-rule configuration;
- a generic positive result could use a registered identity with the wrong
  tool or operation;
- a consecutive final result batch was rejected rather than evaluated as the
  terminal frontier; and
- the first unsupported failed result and exact pre-attempt repeats were not
  handled according to the approved state machine.

The extractor now models versioned verifier facts, exact
`(rule, version, subject kind, subject value)` scope, maximal attempt-action
runs, an owned first following result, and the complete final result frontier.
Earlier result batches remain historical evidence only.  Same-subject opposing
terminal results are typed conflicts; distinct-subject pass/fail results may
form scoped partial success only when the initial subject is covered.

## Causal Language Contract

The deterministic renderer is now version 2.  It distinguishes:

- the **observed sequence** of stored evidence;
- an **associated attempt**, without attributing necessity or effect;
- the **verified-after relationship** between that sequence and terminal
  evidence;
- **explicitly asserted resolution** only as unauthenticated user acceptance,
  which remains review-only; and
- **proven current state**, which the historical Experience explicitly does
  not claim.

Automatic summaries say that terminal evidence was observed after an
associated attempt sequence and scope the episode interpretation to the named
subjects.  They establish neither a dependency on an action nor current-state
validity.

## Adversarial Outcomes

| Case | Result |
|---|---|
| pass after two unrelated edits | one associated attempt; scoped success; no dependency claim |
| broad workspace pass after narrow test failure | `AmbiguousVerificationScope` |
| initial test passes while another test fails | scoped `PartialSuccess` |
| target skipped and zero tests execute | `EmptyVerificationRun` |
| compiler pass after configuration action | verified-after relationship only |
| task marked complete without verifier evidence | `NoVerificationEvidence` |
| same failure prose from another target | `AmbiguousVerificationScope` |
| zero-exit ordinary command with unknown postcondition | attempt action only, never verification |
| acceptance for another subject | `AmbiguousVerificationScope` |
| exact unauthenticated acceptance | inspectable `ReviewRequired` proposal |

The review also aligned the still-unreleased code and graph snapshot models and
`0008` schema with D071: source event, workspace/document revision and hash,
bounded content, optional chunk/symbol/range identity, and coherent graph
revision/analyzer/node/resolution provenance are explicit immutable fields.
Source changes remain review-only until those fields can be captured from a
matching durable historical state.

## Proofs

Thirteen focused consolidation tests now cover the state machine, adversarial
cases, causal renderer, registered-rule validation, terminal-frontier
conflicts, generated-ID-independent proposal hashing, canonical JSON number and
Unicode behavior, and hash domain separation.  The complete project quality
gate passes.

Breakpoint 6 remains the planned Terra/high idempotency and transaction proof.
