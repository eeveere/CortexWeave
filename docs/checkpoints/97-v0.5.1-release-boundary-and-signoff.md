# v0.5.1 Checkpoint 97: Release Boundary and Signoff

v0.5.1 ships qualified test-evidence and historical-retrieval capability, not
an agent-performance claim. The release boundary therefore requires real
Vitest and `unittest` evidence workflows, deterministic core/transport proofs,
and an Experience-exposed emCP smoke plus PiHype fresh-session retrieval.

The attempted matched emCP baseline/assisted comparison is retained as an
invalid qualification artifact. Its baseline did not receive the required
context packet and the local model violated declared tool boundaries. It cannot
support a helped, harmed, or no-material-difference claim. The release notes
and README make that limit visible.

PiHype demonstrated the complete eligible `unittest` workflow: initial failure,
two factual source-edit attempts with failed then passed verification,
automatic Experience consolidation, and a later fresh-session context packet
that retained current evidence and the compatible verified Experience. The
qualification ledger preserves the concrete Event, Episode, Experience, and
capture identifiers.

The release is versioned as 0.5.1. CortexWeave remains a substrate: it returns
bounded evidence and context but does not enforce agent tool budgets, command
execution, or stop conditions. A future harness may address those concerns
without changing this core boundary.

Release validation passed with `cargo fmt --check`, `cargo check`,
`cargo clippy --all-targets -- -D warnings`, and `cargo test`. The release
binary SHA-256 is
