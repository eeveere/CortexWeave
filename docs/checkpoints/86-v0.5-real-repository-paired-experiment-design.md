# v0.5 Checkpoint 86: Real-Repository Paired Experiment Design

**Status:** Complete; revision 6 received a narrow Helped label

Breakpoint 12 now has a frozen paired protocol over the CortexWeave repository.
Task A truthfully records a deterministic Rust `E0425`, a retained still-failing
attempt, a later repair, and passing compiler evidence before explicit
Experience acceptance. Task B applies the analogous mismatch to a different
domain enum arm.

The xhigh execution preflight rejected the original E0308 fixture before either
lane ran because stable compiler JSON does not carry CortexWeave's required
structured expected/actual type distinction. Revision 2 substitutes E0425 so
the real compiler stream can be mapped without parsing diagnostic prose or
inventing evidence.

The same preflight rejected typed source-change attempt Events: v0.5 correctly
marks them review-required when their historical code snapshots are
unavailable, and such proposals cannot be automatically accepted. Revision 3
uses truthful typed editor-completion attempt markers while sealing exact source
diffs and hashes as raw experiment artifacts outside CortexWeave's evidence
claims.

An aborted setup-only run then showed that indexing historical roadmap and
documentation material dominated preparation and that the runner omitted
Cargo's offline flag. Before Task A consolidation or either scored lane,
revision 4 fixed CortexWeave's shared index scope to all `src/**` files and made
compiler invocations offline. Each model still receives the complete repository;
setup time remains outside scored timing.

Baseline and assisted Task B lanes restore the same post-Task-A repository and
SQLite snapshots at the same canonical workspace path. They use one prebuilt
binary, configuration, prompt, model setting, and tool policy. The baseline
omits an active failure signature; the assisted lane supplies the canonical
Task B signature and must select exactly the Task A Experience as historical
supplemental context without displacing current source, task, or failure
evidence.

The protocol fixes mutation anchors, evidence requirements, contamination
checks, measurement definitions, abort conditions, and helped/harmed/null rules
before either scored lane runs. Raw artifacts and confounders are retained, and
no metric may tune production policy. Interpretation remains reserved for the
planned Sol/xhigh pass.

Revision 4 aborted without a comparative label after its baseline completed
but assisted preflight returned `no_eligible_result`. No assisted model was
dispatched. The real-repository case exposed a context-integration defect that
the exact-path fixtures had missed: the active failure's current path and graph
key were being added as hard historical filters, suppressing otherwise
compatible failure-component matches across files and symbols.

Revision 5 is frozen after correcting that production boundary and adding a
cross-path, cross-symbol regression. Explicit Experience-search path and graph
filters remain exact. Experience-aware context instead uses the active
signature's complete identity for exact matching and its normalized components
for compatible matching, without inventing additional hard filters. Revision 5
must rebuild the binary, recreate Task A and the fork point, and rerun both
lanes; no revision-4 model outcome may enter its comparison.

Revision 5 subsequently aborted before assisted model dispatch. Retrieval found
one eligible compatible Experience, but ordinary context used 3,858 of the
4,096-token packet and the remaining 238 tokens could not admit the 381-token
historical item. This was correct one-way budget behavior. The completed
revision-5 baseline is retained only as an aborted raw artifact and receives no
comparative interpretation.

Revision 6 fixes both lane packet budgets at 32,768 after read-only probes showed
that 8,192 still exhausted, 16,384 was an exact-fit boundary, and 32,768
exhausted the finite ordinary candidate pool while retaining 7,544 tokens after
the Experience. It re-seals fresh lane copies of the validated immutable Task A
fork and reruns both model sessions. No prior model output or lane mutation is
reused.

See `docs/experiments/v0.5-real-repository-paired-experiment.md` for the complete
protocol.

Revision 6 passed every lane-validity assertion. Both fresh Sol/xhigh models
restored the exact string literal, produced clean final diffs, and passed
independent offline compiler checks. The assisted packet selected only the
intended active, verified Task A Experience, placed it last as
`historical_supplemental`, and preserved the same 24,843 tokens of ordinary
current context as baseline.

The frozen interpretation rule yields **Helped** because assisted used two
compiler/test cycles versus baseline's three while both succeeded, avoided the
retained failed approach, and displaced no current evidence. This is a narrow
single-case label: the extra baseline cycle was an optional targeted test after
its first verified repair, semantic edit iterations were equal, and assisted
was 3.435 seconds slower to first verification. The result changes no
production policy. Full measurements and artifact hashes are in
`docs/experiments/v0.5-real-repository-paired-experiment-result.md`.
