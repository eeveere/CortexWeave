# v0.4 Phases 9–12: Structural Intelligence

Phases 9–12 expose the reconciled graph through bounded services, add structural
retrieval and context evidence, and provide explainable symbol/file impact.

## Implemented

- `StructuralService` provides exact symbol/path lookup, neighbors, callers,
  callees, references, implementations, tests, dependencies, dependents, and
  bounded typed traversal.
- Structural reads require a current graph by default, verify configured
  analyzer structural versions, reject a graph revision change during a read,
  and preserve explicit stale-read labels when authorized.
- Every traversal and impact report contains its graph revision, applied node,
  edge, and depth limits, paths, confidence, and truncation state.
- Hybrid retrieval adds configurable relation, distance, confidence, and type
  scoring. Exact symbol tokens seed ahead of baseline chunk-derived nodes.
- Structural source mapping prefers an overlapping chunk and deterministically
  falls back to the nearest source chunk for synthetic graph nodes such as test
  declarations.
- Context candidates translate graph paths into caller, callee, reference,
  implementation, test, dependency, dependent, or transitive-impact reasons.
  Evidence survives deduplication and final token-budget selection.
- Impact analysis walks reverse dependencies from either a symbol or a file and
  returns explainable paths without inferring a git diff.

## Breakpoints 8–10

`tests/structural_intelligence.rs` indexes a TypeScript fixture containing an
interface, two implementations, a service calling one implementation, and two
covering tests.

- Breakpoint 8 compares baseline semantic+lexical retrieval with structural
  hybrid retrieval for callers, breakage, implementations, and tests. Baseline
  results have no relationship evidence; structural results identify every
  expected node with typed paths and a current graph label.
- Breakpoint 9 proves “How Interface works?”, “What uses Interface?”, and “What
  changes if Interface changes?” produce different implementation, reference,
  and transitive-impact relation mixes. Final packets retain graph revision and
  traversal-limit provenance within the configured token budget.
- Breakpoint 10 proves interface impact reaches `ImplA`, `ImplB`, `service`,
  `test_a`, and `test_b`, with positive confidence and seed-to-impact paths.
- Additional checks prove one-node/one-edge bounds truncate observably and that
  current-only reads reject a simulated graph error while explicit stale reads
  retain the `Error` snapshot label.
