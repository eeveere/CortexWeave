# v0.4 Phase 16 and Breakpoint 13

## Documentation

`docs/graph-architecture.md` now describes graph ownership, node and edge
semantics, confidence, deterministic symbol resolution, analyzer extension,
impact interpretation, adapter use, status diagnostics, and limitations. CLI
and MCP documentation link to it and include the graph-status surface.

## New-language extension boundary

The automated extension test indexes an unsupported `.lua` source file. It
proves deterministic generic chunking still operates while the graph status
reports the generic analyzer and no structural capabilities. The indexing core,
resolver, structural service, and adapters needed no language-specific change.

## Real-repository evaluation protocol

`tests/real_repository_evaluation.rs` is an explicitly ignored evaluation that
copies the repository selected by `CORTEXWEAVE_EVALUATION_ROOT` into a temporary
workspace and indexes it into a temporary SQLite database with deterministic
local embeddings. It requires a medium mixed-language repository, proves the
projection is current, reports node/edge/unresolved totals and languages, and
exercises bounded structural reads. Its later acceptance edit occurs only in
the temporary copy; it never writes to the evaluated repository.

Run it with:

```text
$env:CORTEXWEAVE_EVALUATION_ROOT = 'C:\path\to\repository'
cargo test evaluates_selected_mixed_language_repository --test real_repository_evaluation -- --ignored --nocapture
```
