# Checkpoint 39: v0.3 Workspace Readiness

## Completed

- The analyzer registry now retains bundled capability metadata independently
  from enabled analyzers.
- The service exposes a read-only workspace readiness report with discovered
  languages, generic fallback classification, scan failures, recommendations,
  and document/chunk/embedding replacement costs.
- CLI and MCP callers can inspect readiness without changing configuration or
  starting a reindex.
- Unsupported text fallback remains healthy; supported languages using generic
  fallback and configured analyzer drift make the workspace not ready.

## Regression Coverage

The acceptance test indexes Python with its analyzer disabled, verifies the
generic rebuild estimate, enables the analyzer through a new service
configuration, and proves that explicit reindexing replaces the old chunks. A
second reindex preserves the resulting chunk identities and embeds nothing.
CLI and MCP integration coverage verifies the public read-only report.

## Boundary

Analyzer enablement remains an explicit caller decision. CortexWeave reports the
available setting and replacement cost but does not edit configuration or start
reconciliation from readiness inspection.
