# CortexWeave v0.5.1 release notes

## Delivered

- Qualified external capture and verification evidence for Vitest 4.1.10 on
  Node 24.19.0 and Python `unittest` on Python 3.14.7.
- Explicit test-run eligibility, runner-qualified compatible failure identity,
  idempotent evidence import, failed-attempt semantics, episode consolidation,
  and immutable verified Experience.
- CLI and MCP evidence recording, inspection, capabilities, stored-failure
  Event context, and safe workspace deregistration.
- `test_evidence_record_file` for bounded workspace-local capture ingestion,
  plus compact MCP evidence responses suitable for small local model contexts.

## Qualification

The emCP Vitest workflow completed an Experience-exposed assisted smoke. PiHype
completed an eligible Python `unittest` failure/attempt/verification episode,
automatic Experience consolidation, and fresh-session historical retrieval.
The supporting record is in the qualification ledger maintained with the
isolated runs.

## Known limitations

No clean matched emCP baseline/assisted model-performance comparison was
obtained. The baseline run was protocol-contaminated, and the product makes no
performance claim. CortexWeave remains a context and evidence substrate; an
external harness owns tool budgets, command execution, and stop conditions.

Only the qualified Vitest and `unittest` profiles are eligible for automatic
verification. Other runners, aggregate commands, watch/focused/filtered runs,
retries, snapshot updates, and unittest subtest-containing scopes remain
inspectable but are not automatic proof.
