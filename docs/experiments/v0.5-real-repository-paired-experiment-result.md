# v0.5 Real-Repository Paired Experiment Result

**Protocol:** Revision 6  
**Status:** Complete  
**Predeclared interpretation:** Helped, narrowly

Revision 6 produced a valid pair. Both fresh GPT-5.6 Sol/xhigh lanes repaired
the exact Task B mutation, passed their model-initiated verification, restored
the repository to a clean state, and passed an independent offline
`cargo check`. The baseline received no Experience. The assisted lane received
exactly the intended active, `verified_passed` Task A Experience as
`historical_supplemental`, after the active task, pinned current failure, and
current source evidence.

Under the frozen interpretation rule, the pair is **Helped**: both lanes
succeeded and avoided the retained unquoted `still_failing` approach, while the
assisted lane used two compiler/test cycles rather than the baseline's three.
It displaced no current evidence and introduced no unrelated change.

This is a narrow protocol label, not a claim of broad model improvement. The
one-cycle reduction came from the assisted model omitting a discretionary
targeted test that baseline ran after its first passing `cargo check`. Semantic
edit iterations were identical, and assisted reached that first passing check
3.435 seconds later. Those contradictory signals and the single-case design
make the result weak evidence outside this exact fixture.

## Interpretation and confounders

The predeclared Helped condition is satisfied by the strict 3-to-2 reduction in
compiler/test cycles. No Harmed condition is supported. Assisted used more
edit-tool invocations, but the raw trace attributes those retries to host patch
transport failures; every attempted patch contained the correct string
literal, so there is no evidence that Experience caused the retry difference.
Selection and authority were correct.

The result also contains null and contrary descriptive signals:

- both lanes had the same task outcome, semantic edit count, retained-approach
  avoidance, and total tool-call count;
- assisted was 3.435 seconds slower to the first passing compiler result; and
- baseline's only extra compiler/test cycle was a post-verification targeted
  test, not a failed diagnosis or repair cycle.

Wall time, provider token use, and tool-transport behavior were explicitly
non-reproducible descriptive measures. This one pair therefore does not justify
changing Experience ranking, budgets, authority, or consolidation policy.
